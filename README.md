# Uroš Petrović – Portfolio

Personal portfolio website of **Uroš Petrović**, a full-stack web developer from Belgrade, Serbia.

The site presents my work, skills and services. I build fast, modern websites, web shops and web applications that help businesses get more clients, bookings and sales.

## About the project

A single-page, fully responsive portfolio built without frameworks, using clean HTML, CSS and JavaScript, with a PHP backend for the contact form. It shows real client projects in device mockups and uses smooth animations throughout. The goal is to make the site feel polished and alive while staying fast.

### Highlights

- **Featured projects in laptop mockups**: real client work displayed on a laptop screen with 3D tilt and scroll-on-hover effects
- **Projects gallery**: browser-window mockups with category filters (Websites, WordPress, Full-Stack)
- **Animated tech stack**: skill cards with animated progress bars, live counters and category filters
- **Client testimonials carousel**: autoplay, arrows, dots and swipe support on mobile
- **Hero section**: typing effect, floating tech icons, animated glow and a scrolling technology marquee
- **Scroll animations**: sections reveal on scroll, with a progress bar, sticky header and back-to-top button
- **Contact form with PHPMailer**: AJAX sending over SMTP, server-side validation, spam protection (honeypot, time check, rate limit) and an automatic reply to the sender
- **Responsive and accessible**: mobile navigation, keyboard support and a reduced-motion mode
